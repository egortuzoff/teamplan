## Сверка статистики (AC-7)

Тестовые данные: сыгранная игра, состав Игрок Первый и Игрок Второй, счёт 2:1; голы — Игрок Первый с передачей Игрока Второго, Игрок Первый без передачи. Будущая игра с составом Игрок Первый и Игрок Второй без счёта.

| Игрок | Ручной подсчёт (игры / голы / передачи) | Экран «Статистика» |
|---|---|---|
| Игрок Первый | 1 / 2 / 0 | 1 / 2 / 0 |
| Игрок Второй | 1 / 0 / 1 | 1 / 0 / 1 |
| Игрок Третий | 0 / 0 / 0 | 0 / 0 / 0 |

Расхождений нет. Будущая игра без счёта в «игры» не засчитана (FR-33). При временном изменении результата на 3:1 (третий гол Игрока Второго с передачей Игрока Первого) статистика пересчиталась: 1/2/1, 1/1/1, 0/0/0; затем результат возвращён к 2:1. То же сравнение выполняет автотест `test_seed_creates_played_game_and_stats_match_manual_count`.

## Замечания

- В контейнере было время UTC, из-за чего проверки «событие началось» и «срок в прошлом» сдвигались на 3 часа. В `docker-compose.yml` добавлен часовой пояс `TZ=Europe/Moscow` (можно переопределить). Первое уведомление о результате в существующей базе создано ещё до исправления и показывает время 19:00 вместо 22:00.
- Запуск без Docker на Python 3.12 и 3.13 на этом компьютере не проверялся: установлен только Python 3.15.
